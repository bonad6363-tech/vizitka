# Надежда Борискина — сайт-визитка

Одностраничный сайт-визитка начинающего digital-специалиста.

## О проекте

Сайт рассказывает, чем занимается Надежда Борискина, какие услуги предлагает, показывает проекты **PULSE** и **АКВАСОТА**, а также помогает быстро связаться через Telegram, email или телефон.

## Структура

- `index.html` — главная страница
- `images/` — фото и скриншоты проектов
  - `portrait.jpg` — фото
  - `pulse.jpg` — проект PULSE
  - `aquasota.jpg` — проект АКВАСОТА

## Как открыть локально

1. Скачайте или клонируйте репозиторий
2. Откройте файл `index.html` в браузере

Или запустите локальный сервер:

```bash
python -m http.server 8080
```

Затем откройте: http://127.0.0.1:8080/
